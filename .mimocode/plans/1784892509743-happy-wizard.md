# План: Переключение dark/light темы через свитчер

## Проблема
Свитчер "Тёмная тема" в `ProfileSettings` переключает локальный `bool`, но `MaterialApp` всегда использует `AppTheme.light`. Тема не меняется.

## Решение
Создать `ThemeCubit` (проект уже использует `flutter_bloc`), подключить его к `MaterialApp` через `BlocProvider`, и вызывать `toggle()` из свитчера.

## Файлы для изменения

### 1. Новый файл: `lib/theme/theme_cubit.dart`
```dart
class ThemeCubit extends Cubit<ThemeMode> {
  ThemeCubit() : super(ThemeMode.light);
  void toggle() => emit(state == ThemeMode.light ? ThemeMode.dark : ThemeMode.light);
}
```

### 2. `lib/main.dart`
- Обернуть `MaterialApp` в `BlocProvider<ThemeCubit>`
- Заменить `theme: AppTheme.light` на `theme: AppTheme.light`, `darkTheme: AppTheme.dark`, `themeMode: context.watch<ThemeCubit>().state`

### 3. `lib/screens/profile_screen.dart`
- Удалить локальный `bool isSwitched`
- Вместо `setState` вызывать `context.read<ThemeCubit>().toggle()`
- Читать текущую тему из `context.watch<ThemeCubit>().state`

### 4. `lib/widgets/profile_widgets/profile_settings.dart`
- Изменить `onDarkModeChanged` — теперь он вызывает `context.read<ThemeCubit>().toggle()`
- Значение свитчера читать из `context.watch<ThemeCubit>().state == ThemeMode.dark`

## Изменения по файлам

| Файл | Что меняется |
|------|-------------|
| `lib/theme/theme_cubit.dart` | **Новый** — Cubit с одним методом `toggle()` |
| `lib/main.dart` | `BlocProvider` + `themeMode` |
| `lib/screens/profile_screen.dart` | Убрать `isSwitched`, читать из cubit |
| `lib/widgets/profile_widgets/profile_settings.dart` | Свитчер вызывает cubit |

## Проверка
1. `flutter analyze lib/` — без ошибок
2. Запустить приложение, перейти в Профиль → Настойки → нажать свитчер → тема должна переключаться на всех экранах
